# Contributing to Geo Agent Framework

Thank you for your interest in improving Geo Agent Framework.

This project is designed to be extended by adding new GEO capabilities while keeping the core workflow reusable.

## Contribution Areas

### 1. AI Engine Adapters

Add support for new AI search engines or answer platforms.

Examples:

- New sampling methods
- New API connectors
- New answer parsers
- New citation extractors

### 2. Brand Adapters

Create reusable templates for different industries:

- SaaS
- E-commerce
- Manufacturing
- Local businesses
- B2B companies

A brand adapter should focus on:

- Facts structure
- Buyer questions
- Trust signals
- Industry-specific GEO rules

### 3. Diagnosis Rules

Improve detection of GEO issues:

- Technical accessibility
- Content structure
- Entity clarity
- Citation opportunities

### 4. Execution Workflows

Add better ways to convert findings into actions:

- Content briefs
- Technical tickets
- Verification methods

## Development Principles

Please keep contributions:

- Brand-agnostic
- Reusable
- Transparent
- Easy to verify

Avoid adding:

- Company-specific private data
- Real customer information
- Proprietary business strategies

## Pull Requests

Before submitting a pull request:

1. Explain the problem being solved.
2. Describe the implementation.
3. Include testing or verification steps.
4. Keep changes focused.

Thank you for helping build open GEO infrastructure.
